最终设计：bridge/ 包

一个包统一管理 TUI 渲染的生产和消费

bridge/
├── renderEvent.go   ← Target 常量 + RenderEvent（无 tview）
├── eventBus.go      ← EventBus + Emit/Shutdown 包级函数（无 tview）
├── widgetOps.go     ← WidgetOpsImpl 接口 + WidgetOps 变量（无 tview）
└── tuiRender.go     ← 渲染 goroutine + WidgetOps tview 实现（唯一 import tview）

业务层只 import "HyperBot/bridge"

bridge.Emit(RenderEvent{TargetMessage, Content})
bridge.WidgetOps.EnableInput(prompt, onSubmit)
