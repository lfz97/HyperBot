# HyperBot 🤖

一个运行在终端里的 AI Agent 聊天机器人——支持 OpenAI / Anthropic 多模型、任意 MCP 工具接入、本地命令全生命周期管理，开箱即用。

## 能做什么

### 🖥️ 终端里的 AI 助手

基于 [tview](https://github.com/rivo/tview) 构建的双页面 TUI 界面：启动配置页 → 对话页，支持鼠标操作和 bracketed paste，长文本粘贴流畅不卡顿。所有交互都在终端中完成，无需浏览器。

### 🤖 多模型自由切换

同时支持 OpenAI 兼容接口（GPT-4o、DeepSeek 等）和 Anthropic Claude 系列。一个配置文件切换模型，DeepSeek 自动适配变体参数。

### 🔄 实时流式输出

支持流式和非流式两种模式。流式模式下，推理过程（reasoning）以黄色暗色文本高亮展示，工具调用实时可见，响应过程一目了然。

### 🔧 MCP 工具统一接入

通过 YAML 列表配置任意数量的 MCP 工具集，三种传输方式全覆盖：

| 方式 | 说明 |
|------|------|
| SSE | HTTP Server-Sent Events，适合远程 MCP 服务 |
| Streamable HTTP | HTTP 流式传输，适合现代 MCP 服务端 |
| Stdin MCP | 通过 `command + args` 启动本地子进程，如 `npx -y mcp-exec` |

### 💻 本地命令全生命周期

内置 `localexec` 工具集，6 个工具覆盖命令完整生命周期：

```
提交命令 → 启动执行 → 轮询状态 → 读取输出 → 干预运行（stdin / 信号） → 强制终止
```

Agent 可以自主完成"写代码 → 编译 → 运行 → 调试"的完整闭环。

### 📚 知识注入式技能系统

将 `.hyperbot/skills/` 下的 `SKILL.md` 自动加载为 Agent 知识上下文。技能只提供知识引导，不单独生成执行工具——所有命令统一走 `localexec`，避免重复造轮子。

创建自定义技能只需两个文件：

```
.hyperbot/skills/my-skill/
├── SKILL.md           # 技能定义（必须）
└── references/        # 参考文档（可选）
    └── guide.md
```

### 🧠 智能会话摘要

长对话自动压缩历史，确保不超出模型上下文窗口：

- **精准 token 计数**：基于 [tiktoken](https://github.com/tiktoken-go/tokenizer) 按模型规则计数，比简单字符估算准确得多
- **多条件触发**（任一满足即压缩）：事件数 ≥ 20 / 新增 token ≥ 150K / 无活动超过 10 分钟
- **结构化摘要**：强制 9 段模板输出，确保压缩质量
- **实时回显**：生成的摘要以绿色文本显示在对话区，随时可查看
- **异步执行**：后台并发压缩，不阻塞主对话

### 💬 会话管理

- **多轮对话记忆**：Session 级上下文保持
- **`/new`**：随时开始新对话
- **`/flush`**：热重载 MCP 工具配置，不丢失对话历史
- **`ESC`**：随时中断 Agent 当前响应
- **自动恢复**：出错后 Agent 自动以错误信息构造 recover prompt 尝试自我修复，不让一次性 5xx 打断对话

### 📝 跨会话操作记录

复杂任务中 Agent 自动将关键操作写入 `.hyperbot/OperationRecord.md`，后续对话可回溯上下文，不会"失忆"。

## 快速开始

### 环境要求

- **Go 1.26+**
- OpenAI 兼容或 Anthropic API Key

### 安装运行

```bash
git clone https://github.com/lfz97/HyperBot.git
cd HyperBot

# 直接运行
go run .

# 或编译后运行
go build .
./HyperBot
```

首次运行会自动生成配置文件和技能目录，修改 API Key 后重新启动即可。

### 交互指令

| 操作 | 功能 |
|------|------|
| 输入文本 + `Ctrl+Enter` | 发送消息（Enter 换行） |
| `/new` | 开始新对话，重置会话上下文 |
| `/flush` | 热重载配置，仅重建工具集，保留会话 |
| `/exit` | 退出程序 |
| `ESC` | 中断当前 Agent 响应 |

## 配置

首次运行自动生成 `.hyperbot/hyperbot.yaml`：

```yaml
user:
  userid: "<auto-generated-uuid>"

model:
  model: "deepseek-reasoner"      # 模型名
  baseurl: "https://api.deepseek.com"
  apikey: "your-api-key"
  apitype: "openai"               # openai 或 anthropic
  contextwindow: 64000            # 上下文窗口大小
  stream: true                    # 是否启用流式输出

# HTTP MCP 服务（可配置多个）
mcp:
  - name: "my-mcp"
    enabled: true
    type: "sse"                   # sse 或 streamable_http
    endpoint: "http://127.0.0.1:8080/mcp"
    headers: {}
    # headers: {"Authorization": "Bearer xxx"}

# Stdin MCP（子进程方式启动本地 MCP）
stdin_mcp:
  - name: "local-tool"
    enabled: true
    command: "npx"
    args: ["-y", "mcp-exec"]
```

### 支持的模型

| API 类型 | 模型示例 |
|----------|----------|
| `openai` | `deepseek-reasoner`、`deepseek-chat`、`gpt-4o`、`gpt-4o-mini` |
| `anthropic` | `claude-sonnet-4-6`、`claude-opus-4-6` |
