最终方案：EventBus + WidgetOps

重构前后对比

重构前：所有包直接依赖 global TUI widgets

  handler/runOnce.go ──→ global.Print2AgentMessageView()
  handler/message.go ──→ global.Print2AgentMessageView()
  handler/runIteratively ──→ global.Sidebar, InputArea, StatusBar, App_p
  session/summarizer.go ──→ fmt.Fprint(global.AgentMessage, ...)
  bootstrap/Initializer.go ──→ global.Print2LogView(), App_p
  bootstrap/Bootstrap.go ──→ global.AgentMessage, App_p

  每个包都 import 了 "HyperBot/global" + "HyperBot/utils/pretty"

重构后：业务层只依赖 output 包

                    ┌────────────────────┐
                    │  output/           │
                    │  ├─ RenderEvent     │
                    │  ├─ EventBus        │
                    │  └─ WidgetOps       │
                    └──┬──────────────┬──┘
                       │              │
              ┌────────▼────┐  ┌─────▼──────────┐
              │  业务层      │  │  渲染层 (TUI)    │
              │  handler/   │  │  tui/renderer   │
              │  bootstrap/ │  │  (唯一import     │
              │  session/   │  │   tview/tcell)  │
              │             │  │                 │
              │ EventBus    │  │ goroutine 消费   │
              │ .Emit(evt)  │  │ events → Queue   │
              │             │  │ UpdateDraw      │
              │ WidgetOps   │  │                 │
              │ .SetFocus() │  │                 │
              └─────────────┘  └─────────────────┘
